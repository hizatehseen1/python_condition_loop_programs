Student Scholarship Eligibility System

About Project

This is a Python-based program that checks students' eligibility for university scholarships based on academic marks, attendance, and monthly family income.

Features

Enter student information.

Validate entered data.

Check scholarship eligibility.

Award full scholarship (90% or above).

Award partial scholarship (80% to 89%).

Display reasons for ineligibility.

Generate a scholarship evaluation report.

Technologies Used

Python 3

VS Code

How to Run

Open the project in Visual Studio Code.

Open the terminal using `Ctrl + ``.

Navigate to the project folder:

cd "program 1"

Run the program:

python scholarship.py

For Windows, you can also use:

py scholarship.py
