Smart Pharmacy Inventory & Sales System

About Project

This is a Python-based program that manages medicine stock and sales. It calculates total revenue, checks available stock, and identifies medicines that need restocking.

Features

Enter medicine details.

Check available stock.

Calculate medicine sales.

Calculate total revenue.

Show low-stock warnings.

Generate a final sales report.

Technologies Used

Python 3

VS Code

How to Run

Open Visual Studio Code.

Open the terminal using `Ctrl + ``.

Navigate to the Pharmacy folder:

cd "program 2"

Run the program:

python pharmacy.py

For Windows, you can also use:

py pharmacy.py

Inputs Required

After running the program:

Enter the number of medicines (e.g., 2).

Enter the medicine name.

Enter available stock.

Enter price per unit.

Enter quantity sold.

Repeat these steps for each medicine.
